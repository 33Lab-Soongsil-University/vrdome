둥근 드롭다운 UI 구조

씬: Assets/Scenes/quest3_dome.unity
Quest 3 XR Origin의 DomeQuestViewer가 Start -> BuildMenu에서
Quest world menu(Canvas, World Space)를 만들고 DomeDropdownMenu를 초기화합니다.
UI 프리팹을 Inspector에 연결하는 방식이 아니며 실행 중에 생성됩니다.

Assets/Scripts/DomeDropdownMenu.cs (신규)
Initialize: 좌석, 영상, Controls 버튼과 펼침 목록 생성.
Toggle / Close / Layout: 한 번에 하나의 목록을 열고 아래 버튼 위치 재배치.
RefreshView: 현재 좌석 이름, 영상 이름, 재생 상태를 버튼에 반영.
RefreshRows: 14개 영상 목록을 6개씩 표시. 마지막 페이지의 빈 항목은 비활성화.
BuildRoundedSprite: 둥근 스프라이트를 코드로 생성하고 Sliced Image로 버튼 크기에 맞춤.
각 버튼은 기존 viewer.SelectSeat, library.Select, TogglePlayback 등에 연결됩니다.
색은 Normal/Highlight, 너비는 Width, 행 간격은 Row에서 수정합니다.

Assets/Scripts/DomeQuestViewer.cs (수정)
BuildMenu: 중앙 패널 대신 DomeDropdownMenu 생성 및 버튼 Collider 등록.
PlaceMenu: PC에서는 화면 오른쪽 위를 3D 좌표로 바꾸어 배치.
VR에서는 시선 오른쪽의 공간에 고정하며 메뉴 재열기/좌석 변경 때 위치 갱신.
DesktopMenuInput: 마우스 레이로 활성 버튼만 검사.
VR 컨트롤러 레이도 같은 버튼과 동작을 사용합니다.
OnGUI: 기존 하단 안내와 큰 버튼 제거. 메뉴 숨김 상태의 다시 열기 버튼만 유지.
기존 키보드, 컨트롤러, 시선 선택 기능은 유지합니다.

Assets/Scripts/Editor/DomeQuestVerification.cs (수정)
실제 마우스 레이 경로로 좌석 선택과 이름 갱신, 목록 닫힘,
영상 페이지 이동/선택, 재생/정지/재시작, 시점 초기화, 메뉴 숨김을 검사합니다.
모의 VR 전환 검사는 실제 Quest Link 기기 검증을 대체하지 않습니다.

Play 중 Inspector에서 바꾼 UI는 정지하면 사라집니다.
영구적인 UI 디자인 변경은 DomeDropdownMenu.cs를 수정하세요.
